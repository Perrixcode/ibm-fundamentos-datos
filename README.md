# Fundamentos de los Datos — práctica de GitHub

Repositorio de práctica de la lección **Git y GitHub** del curso **Descripción general de herramientas y lenguajes de datos**, parte del plan Fundamentos de los Datos de IBM SkillsBuild.

## Objetivo

Practicar la creación de un repositorio, documentarlo con un README y agregar un archivo CSV mediante un commit.

## Archivo de ejemplo

- `german_credit_data_biased_training.csv`: conjunto de datos de capacitación enlazado por IBM SkillsBuild.
- [Fuente del archivo proporcionada por el curso](https://ibm.box.com/shared/static/e09ka2u5hrxww8ymcxmcwvtojdmvygk0.csv).

El curso describe estos datos como ficticios y destinados únicamente a capacitación. Este repositorio los conserva sin modificaciones para realizar la actividad. No deben usarse para decisiones crediticias reales.

## Cómo revisar la práctica

Abre el CSV para explorar su estructura tabular y consulta el historial de commits para ver la incorporación de los archivos.
